关于扩展

NodeSeek Expansion Tool 是 NodeSeek / DeepFlood 非官方 Chromium MV3 扩展，以网页附加功能为主、信息通知为辅，提供用户标签、内容管理、自动传图、签到提醒、阅读导航、快捷评论、快捷短语、抽奖通知、站内消息通知、访问足迹和同步备份等实用功能。

隐私声明

  • 扩展没有开发者账户、遥测统计、广告追踪或远程配置中心，不会把本地保存的配置、缓存和通知记录上传给插件作者。
  • 界面主题、功能开关、标签样式、关键词、快捷短语、浏览历史、访问标记、好友、黑名单、回帖足迹、通知状态和签到记录保存在浏览器本地。
  • NodeImage API Key、通知渠道 Token、API Key、Webhook、邮件地址等敏感配置仅用于用户主动启用的功能，并保存在 chrome.storage.local。
  • 扩展不会读取浏览器密码、支付信息、Cookie 明文、自动填充资料、通讯录、精确位置、摄像头或麦克风，也不会收集与论坛功能无关的网站浏览记录。
  • 图片只在用户主动选择、粘贴或拖放时读取；未填写或未启用的通知渠道不会收到论坛数据，关闭“私信摘要”后不会向外部渠道发送私信正文预览。
  • “用户信息导出”不包含访问、抽奖、签到或通知记录；“完整备份”可能包含 API Key、Token、Webhook、快捷短语、历史和用户关系数据。请妥善保管，不要公开上传完整备份文件。

数据边界

浏览 NodeSeek / DeepFlood、检查签到状态或监控艾特、回复、私信时，扩展只访问当前论坛页面及对应接口，并使用当前浏览器登录会话。内容脚本只注入 NodeSeek 与 DeepFlood。

启用图片上传后，扩展只把用户主动选择的图片文件和 NodeImage API Key 发送到 api.nodeimage.com；请求头规则也仅作用于该上传接口。

启用外部通知后，通知标题、正文或摘要、帖子链接及渠道认证配置会发送到用户选择的 Telegram Bot、邮件、微信推送、企业微信、钉钉或飞书服务。扩展不会把这些内容转发到插件作者服务器。

storage 用于保存本地数据，tabs 用于打开或刷新论坛页面及完成备份通信，alarms 用于定时检查通知，notifications 用于显示浏览器桌面通知，HTTPS 访问用于论坛、NodeImage 和用户配置的通知服务。

本扩展不隶属于 NodeSeek、DeepFlood、NodeImage 或任何通知服务提供商。使用第三方服务时还应遵守相应服务条款；论坛页面结构或接口变化可能影响部分功能。
